OccidamusSimul was my first collaborative software project, developed with a high school friend as an opportunity to experience a more professional development workflow. The project introduced us to team coordination, version control, peer-to-peer communication, multiplayer game mechanics, and the fundamentals of game design. Although unfinished, it provided valuable experience in collaborative software development and laid the foundation for many of the projects that followed.

The game had a basic way to access and create a room to play with someone else through the Photon API for servers. Players would spawn as a small knight with a sword that swerved around them, which could damage the other player or red blobs.

Traffic Optimisation Platform

Jul 2026 On-Going
  • Kotlin
  • Python
  • Server-Client
  • Parallel Computing
  • AI
  • Ant Colony Optimization
  • Simulation
  • Graph Algorithms
  • OpenStreetMap

Large-scale university research project focused on modeling, simulating, and optimizing urban traffic in Iași using real-world road network data. The platform follows a distributed server-client architecture with interprocess communication, parallel simulation, and modular services. It combines microscopic and macroscopic traffic simulation, graph-based road modeling, adaptive traffic light control, and bio-inspired optimization algorithms such as Ant Colony Optimization (ACO). I coordinate a multidisciplinary team consisting of two Computer Science students and one Systems Engineering student, overseeing the project architecture, task planning, software integration, and development.

Team

Three-member multidisciplinary team consisting of two Computer Science students and one Systems Engineering student.

Main Features

  • Distributed server-client architecture
  • Interprocess communication between platform modules
  • Parallelized traffic simulation
  • Microscopic and macroscopic traffic models
  • Hybrid simulation engine
  • Graph-based road network representation
  • Real OpenStreetMap data integration
  • Adaptive traffic light simulation
  • Ant Colony Optimization (ACO)
  • Traffic flow visualization
  • Command-line utilities for simulation management
  • Performance evaluation and statistical analysis tools

Technologies

Kotlin, Python, OpenStreetMap, Multithreading, Parallel Computing, Interprocess Communication (IPC), Server-Client Architecture, Graph Algorithms, Artificial Intelligence, Simulation Systems.

Planned mobile application focused on generating personalized travel itineraries using Artificial Intelligence and Genetic Algorithms. The system will model cities as weighted graphs built from real-world mapping data, combining user preferences, routing constraints, attraction clustering, and adaptive learning to generate optimized vacation plans that maximize sightseeing opportunities while remaining within user-defined time and distance limits.

Status

Currently in the planning and research phase. The mathematical model, optimization strategy, and overall system architecture are being designed before implementation begins.

Main Features

  • AI-powered personalized travel itinerary generation
  • Genetic Algorithm optimization engine
  • User preference learning and adaptation
  • Weighted graph representation of cities
  • OpenStreetMap integration
  • Automatic attraction clustering
  • Route optimization under time and distance constraints
  • Discovery of hidden attractions along optimized routes
  • Restaurant and hotel recommendations

Technologies

Kotlin, Android, Genetic Algorithms, Artificial Intelligence, Graph Theory, Optimization Algorithms, OpenStreetMap, REST APIs, Databases, Mobile Development, Route Planning, Machine Learning Concepts.
